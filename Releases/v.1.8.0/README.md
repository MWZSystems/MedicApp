- Guardado validado, control de concurrencia y auditoría por ajuste; acceso administrativo.
- 121 pruebas aprobadas y compilación Release sin advertencias.
- Sin migraciones ni cambios de datos. Se conserva la configuración existente; publicar sin InitializeCalendar.
- El ZIP excluye App_Data, evidencias, claves, conexiones y perfiles privados.
- La guía PowerPoint incluida corresponde a la versión 1.7.0.
