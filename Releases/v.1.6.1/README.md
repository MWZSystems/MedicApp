# MedicApp 1.6.1

Botón con icono y texto para mostrar/ocultar la contraseña del login. Compatible con teclado, etiquetas accesibles y estado anunciado. La contraseña comienza oculta y vuelve a ocultarse al enviar el formulario o salir de la página. JavaScript local; no almacena ni modifica el valor de la contraseña.

- 104 pruebas aprobadas, compilación Release sin advertencias y comprobación funcional del toggle.
- Sin migraciones, cambios de datos, permisos, configuración o autenticación.
- Requiere la base instalada de 1.6.0. Publicar con el script oficial sin InitializeCalendar.
- Conservar SQL, App_Data/Evidence y App_Data/Keys. El ZIP excluye documentos, datos, claves, conexiones y perfiles privados.

Entrega inmutable. Verificar SHA256SUMS.txt antes de desplegar. SourceCommit identifica el código; la etiqueta incluye los metadatos de entrega.
